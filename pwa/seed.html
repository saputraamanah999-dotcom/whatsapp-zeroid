Zeroid WhatsApp — Seed Firebase

Alat ini membuat koleksi & dokumen awal Firebase secara otomatis dan menyiapkan akun developer/admin. Idempotent — aman dijalankan berulang (yang sudah ada dilewati). Isi konfigurasi web app dari Firebase Console → Project settings → General → Your apps → SDK setup and configuration → Config.

1 · Konfigurasi Firebase

2 · Akun Developer / Admin

Akun dibuat bila belum ada, lalu diberi role: "developer". Pengangkatan role memakai pintu bootstrap: hanya boleh selama dokumen config/bootstrap belum ada — alat ini langsung membuatnya setelah selesai, sehingga pintu tertutup permanen.

3 · Jalankan

⚠️ Pertama: publish firestore.rules versi terbaru (dari ZIP, ada klausa bootstrap) di Firebase Console → Firestore Database → Rules. Tanpa itu, langkah role akan permission-denied.
