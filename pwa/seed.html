Zeroid WhatsApp — Seed Firebase (v6)

Membuat SEMUA koleksi & dokumen awal Firebase otomatis (chat global, saluran Zeroid AI, config, akun developer). Idempotent — aman dijalankan berulang. Config di bawah sudah terisi untuk project baru whatsapp-zeroid; kalau ganti project lagi, cukup isi ulang lalu jalankan.

1 · Konfigurasi Firebase

2 · Akun Developer / Admin

Akun dibuat bila belum ada, lalu diberi role: "developer" + blueCheck: true. Pintu bootstrap (kenaikan role) hanya terbuka selama config/bootstrap belum ada — alat ini membuatnya otomatis setelah selesai supaya pintu terkunci permanen.

3 · Rules (WAJIB — sekali setelah ganti project)

Buka Firebase Console → Firestore Database → Rules → hapus semua → tempel isi di bawah → Publish. Versi ini sudah memperbaiki: Story gagal (toleransi jam HP), patungan centang biru, vote polling, mute anti-spam, dan limit pembelian.

4 · Indexes (WAJIB — sekali klik)

Notifikasi realtime, riwayat panggilan, dan pesanan butuh composite index. Klik tombol di bawah — Console terbuka dengan index sudah terisi otomatis untuk project yang diisi di atas, tinggal tekan Create index. Tunggu status jadi Enabled (1–3 menit).

5 · Jalankan

⚠️ Pertama: aktifkan Authentication → Sign-in method → Email/Password di project baru, lalu publish Rules (langkah 3). Setelah itu klik seed di bawah.
