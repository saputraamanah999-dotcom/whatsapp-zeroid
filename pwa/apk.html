Cara pasang di HP

  1. 1Ketuk Unduh APK Terbaru di atas (boleh dari HP langsung).
  2. 2Buka file yang terunduh. Bila muncul peringatan (mis. "Tidak dapat memverifikasi pengembang aplikasi" / sumber tidak dikenal): ketuk Detail / Tutup → coba lagi → pilih Tetap instal. Ini normal untuk APK di luar Play Store — APK ini ditandatangani kunci resmi Saputra Developer.
  3. 3Uninstall dulu versi lama yang crash (v1.2.0), lalu instal build ini. Data akun aman — tinggal login lagi.
  4. 4Setujui izin Notifikasi di buka pertama — push FCM native aktif.

Sudah diperbaiki di build ini

AKHIRNYA TIDAK LAGI FORCE CLOSE — mode R8/perkecil yang membuat aplikasi crash saat dibuka dinonaktifkan total; aplikasi kini dibuka stabil di semua HP.
Nama aplikasi kini "Zeroid" (Saputra Developer) — tidak lagi memancing deteksi palsu "phishing" saat instalasi.
Gaya balon + wallpaper + tema chat — pilih gaya balon, wallpaper, dan tema warna; terlihat real-time oleh temanmu.
Foto Live, stiker Brat emoji iPhone, musik latar belakang, masukan ke developer — semua fitur baru di build ini.

Versi baru dipasang langsung di atas versi lama (kunci tanda tangan sama) — tanpa hapus data, tanpa login ulang. Cukup unduh lagi dari halaman ini dan instal.
