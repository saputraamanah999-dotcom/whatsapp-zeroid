Unduh APK Zeroid

Aplikasi Android asli Zeroid WhatsApp — notifikasi push FCM native masuk walau aplikasi ditutup, panggilan lebih stabil, dan buka lebih cepat dari web.

Unduh APK Terbaru Riwayat versi (GitHub Releases) Build ulang via GitHub Actions

Tautan mati / belum ada build? Buka tab Actions → Build APK Zeroid → Run workflow, tunggu ±15–25 menit, lalu unduh artefak zeroid-apk.

📲 Cara pasang di HP

  1. 1Ketuk Unduh APK Terbaru di atas (boleh dari HP langsung).
  2. 2Buka file yang terunduh. Bila muncul peringatan, pilih Tetap instal / izinkan Sumber tidak dikenal untuk browser ini (APK di luar Play Store memang begitu).
  3. 3Instal seperti biasa, buka Zeroid, masuk dengan akunmu.
  4. 4Setujui izin Notifikasi di buka pertama — push FCM native aktif.

✅ Sudah diperbaiki di build ini

✓Crash saat buka aplikasi (NoClassDefFoundError) — modul Expo tidak selaras; seluruh 15 modul native kini dipaskan ke SDK 57 (expo-location 19→57, dll).
✓Koin & check-in tampil benar — saldo, beruntun, dan tombol check-in kini ikut data server.
✓Animasi mengetik Zeroid AI — titik-titik "sedang mengetik…" di chat AI, header, dan daftar chat.
✓Chat real-time — pesan, badge, hapus riwayat panggilan langsung tanpa delay.
✓Notifikasi FCM native — masuk walau aplikasi ditutup (google-services.json menyatu).

🔁 Update aplikasi

Versi baru dipasang langsung di atas versi lama (keystore sama) — tanpa hapus data, tanpa login ulang. Cukup unduh lagi dari halaman ini dan instal.
