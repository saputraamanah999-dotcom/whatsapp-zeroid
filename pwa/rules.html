🛡️ Pasang Rules Firebase — 2 menit, dari HP

Rules di server Firebase masih versi lama. Akibatnya: check-in ditolak (padahal belum check-in), referral mati, foto sekali lihat bisa dibuka berkali-kali, dan catatan IP/perangkat ban tidak tersimpan. Teks di bawah adalah rules terbaru v12 (otomatis ikut versi terbaru saat build). Setelah dipasang, semua fitur langsung hidup tanpa update aplikasi.

Cara 1 — Publish manual (tercepat)

1
Buka console.firebase.google.com → Firestore Database → Rules (login akun Google pemilik project).
2
Ketuk tombol di bawah — seluruh teks rules terbaru tersalin ke papan klip.
3
Hapus SEMUA teks lama di editor Rules Console, lalu tempel dan ketuk Publish.
4
(Opsional, disarankan) lakukan yang sama untuk Storage: Storage → Rules — pakai tombol kedua.
✅ Tersalin! Sekarang tempel di editor Rules Console Firebase, lalu Publish.

Cara 2 — Otomatis selamanya (GitHub Actions)

    

      Supaya rules otomatis ter-update setiap kali ada push: buat service account key
      (Firebase Console → ⚙️ Project settings → Service accounts → Generate new private key → unduh JSON),
      lalu di GitHub repo: Settings → Secrets and variables → Actions → New repository secret,
      Nama: FIREBASE_SERVICE_ACCOUNT, Isi: seluruh isi file JSON tadi.
      Workflow deploy-rules.yml sudah disiapkan — setiap push yang mengubah rules akan
      ter-deploy otomatis tanpa disentuh lagi.
